\# Governed Agentic RAG



This project builds a governed agentic RAG pipeline and evaluates the safety-cost trade-off of adding governance controls.



\## Core Governance Controls



\- Permission-aware retrieval using ACL/RBAC metadata

\- Prompt-injection and poisoning detection

\- PII detection/redaction

\- Grounding and citation checks

\- Audit logging
